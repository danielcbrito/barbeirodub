>>> INÍCIO DO PROMPT

Implemente uma barra de navegação inferior (bottom nav) mobile EXATAMENTE
igual à especificação abaixo. Não invente variações: siga medidas, cores,
comportamento e o código dos ícones ao pé da letra.

--------------------------------------------------------
1) CONCEITO VISUAL
--------------------------------------------------------
- Barra fixa no rodapé, ocupando toda a largura, fundo SÓLIDO (nunca
  translúcido/blur — isso bugga scroll no iOS).
- Fundo: token `bg-background` (branco no modo claro, #0D0D0D no escuro).
- Borda superior fina: `border-t border-border/60`.
- 4 abas distribuídas igualmente (`justify-around`, cada item `flex-1`).
- Cada item: ícone em cima + label em baixo, centralizados, gap de 6px.
- Estado INATIVO: ícone em CONTORNO (outline) na cor do texto padrão
  (`text-foreground` → preto no claro, branco no escuro). Label peso medium.
- Estado ATIVO: ícone PREENCHIDO em vermelho (`text-accent-red`), com os
  detalhes internos redesenhados na cor do fundo (branco no claro,
  preto no escuro) por cima do preenchimento. Label peso semibold, vermelha.
- REGRA DE OURO DOS ÍCONES: o desenho NÃO muda entre inativo e ativo.
  É a MESMA silhueta; ativo apenas preenche em vermelho e redesenha os
  detalhes internos usando `stroke="hsl(var(--background))"`.

--------------------------------------------------------
2) ESPAÇAMENTOS EXATOS
--------------------------------------------------------
- Container interno: `flex items-start justify-around px-2 pt-2 pb-0`
- Item: `flex flex-1 flex-col items-center gap-1.5 px-2 py-1`
- Ícones: 22x22px (`h-[22px] w-[22px]`); o Home pode usar 26px se quiser
  peso visual maior.
- Label: `text-[12px] leading-none`.
- Badge (contador): `absolute -top-2 -right-2.5`, `min-w-[19px] h-[19px]`,
  `px-1 rounded-full bg-accent-red text-white text-[10px] font-bold`,
  `ring-2 ring-background` (anel que "recorta" o badge do ícone).
  Mostra "99+" acima de 99.
- Safe area iPhone via CSS vars (não hardcode):
    bottom: var(--app-bottom-nav-offset, 0px);
    paddingBottom: var(--app-safe-bottom, env(safe-area-inset-bottom, 0px));
- "Bleed": uma div absoluta abaixo da barra, `translate-y-full`,
  `bg-background`, altura `var(--app-bottom-nav-bleed, 0px)`, para
  eliminar a faixa branca que aparece embaixo no PWA iOS no modo escuro.
- z-index: `z-50` e `overflow-visible` (senão o badge é cortado).

--------------------------------------------------------
3) TOKENS DE COR NECESSÁRIOS
--------------------------------------------------------
No CSS global defina (HSL, sem cor hardcoded nos componentes):
  --background, --foreground, --border, --accent-red
E no Tailwind:
  colors: { "accent-red": "hsl(var(--accent-red))" }
Sugestão de vermelho: #B8351E (hsl aproximado: 9 71% 42%).

import type { SVGProps } from "react";

OBSERVAÇÕES IMPORTANTES SOBRE OS ÍCONES:
- São os MESMOS paths dos ícones Lucide (home, calendar, send, user-circle),
  só que reescritos à mão para permitir o modo "preenchido".
- `stroke="currentColor"` faz o ícone herdar automaticamente preto/branco
  no inativo e vermelho no ativo — não hardcode cor nenhuma.
- Os detalhes internos no estado ativo usam `hsl(var(--background))`,
  então "a pontinha fica branca" no modo claro e preta no modo escuro,
  automaticamente.

import { NavLink, useNavigate, useLocation } from "react-router-dom";
import { cn } from "@/lib/utils";
import { CalendarNavIcon, HomeNavIcon, ProfileNavIcon, SendNavIcon } from "./AppNavIcons";

interface AppMobileNavProps {
  basePath: string;   // ex: "/barbeiro" ou "/admin"
  badgeCount?: number; // contador exibido sobre o ícone da Agenda
}

const items = [
  { key: "inicio", label: "Início", path: "", end: true, Icon: HomeNavIcon },
  { key: "agenda", label: "Agenda", path: "/agenda", Icon: CalendarNavIcon, badge: true },
  { key: "disparo", label: "Disparo", path: "/disparo", Icon: SendNavIcon },
  { key: "perfil", label: "Perfil", path: "/perfil", Icon: ProfileNavIcon },
];

export function AppMobileBottomBar({ basePath, badgeCount = 0 }: AppMobileNavProps) {
  const navigate = useNavigate();
  const location = useLocation();

  return (
    <nav
      className="fixed bottom-0 left-0 right-0 z-50 bg-background border-t border-border/60 overflow-visible"
      style={{
        bottom: "var(--app-bottom-nav-offset, 0px)",
        paddingBottom: "var(--app-safe-bottom, env(safe-area-inset-bottom, 0px))",
      }}
    >
      {/* bleed: evita faixa branca embaixo no PWA iOS */}
      <div
        aria-hidden="true"
        className="pointer-events-none absolute inset-x-0 bottom-0 translate-y-full bg-background"
        style={{ height: "var(--app-bottom-nav-bleed, 0px)" }}
      />

      <div className="flex items-start justify-around px-2 pt-2 pb-0">
        {items.map(({ key, label, path, end, Icon, badge }) => {
          const to = `${basePath}${path}`;
          return (
            <NavLink
              key={key}
              to={to}
              end={end}
              // navegação no pointerdown = resposta instantânea ao toque
              onPointerDown={(e) => {
                if (e.pointerType === "mouse" && e.button !== 0) return;
                if (location.pathname !== to) navigate(to);
              }}
              onClick={(e) => e.preventDefault()}
              className={({ isActive }) =>
                cn(
                  "flex flex-1 flex-col items-center gap-1.5 px-2 py-1 transition-colors duration-150 touch-manipulation select-none",
                  isActive ? "text-accent-red" : "text-foreground"
                )
              }
            >
              {({ isActive }) => (
                <>
                  <div className="relative">
                    <Icon className="h-[22px] w-[22px]" active={isActive} aria-hidden="true" />
                    {badge && badgeCount > 0 && (
                      <span
                        className="absolute -top-2 -right-2.5 min-w-[19px] h-[19px] px-1 rounded-full bg-accent-red text-white text-[10px] font-bold flex items-center justify-center leading-none ring-2 ring-background"
                        aria-label={`${badgeCount} agendamentos`}
                      >
                        {badgeCount > 99 ? "99+" : badgeCount}
                      </span>
                    )}
                  </div>
                  <span className={cn("text-[12px] leading-none", isActive ? "font-semibold" : "font-medium")}>
                    {label}
                  </span>
                </>
              )}
            </NavLink>
          );
        })}
      </div>
    </nav>
  );
}

--------------------------------------------------------
7) CRITÉRIOS DE ACEITE
--------------------------------------------------------
[ ] Ícone inativo = contorno preto (claro) / branco (escuro).
[ ] Ícone ativo = MESMA silhueta preenchida em vermelho, com os detalhes
    internos na cor do fundo (branco no claro, preto no escuro).
[ ] Label 12px, semibold+vermelha quando ativa.
[ ] Nada de blur/transparência no fundo da barra.
[ ] Badge redondo com anel do fundo, não é cortado pela barra.
[ ] Sem faixa branca no rodapé no iPhone em PWA modo escuro.
[ ] Toque responde instantâneo (pointerdown), sem delay de 300ms.
